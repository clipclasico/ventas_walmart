# Walmart Sales Analysis | Power BI

Proyecto académico desarrollado en **Power BI** para analizar datos históricos de ventas de Walmart mediante dashboards e indicadores.

## Herramientas utilizadas

* Power BI
* Análisis de datos
* Visualización de datos
* Indicadores (KPIs)

## Sobre el proyecto

Este proyecto fue realizado con fines académicos como parte de mi formación en Ingeniería en Ciencia de Datos en la Universidad del Valle de Guatemala.
